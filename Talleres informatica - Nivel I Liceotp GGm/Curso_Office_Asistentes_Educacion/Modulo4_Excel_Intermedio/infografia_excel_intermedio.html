La Función SI: El Semáforo Lógico de Calificaciones

❌

2

BUSCARV: El Asistente que Encuentra Apoderados al Instante

=BUSCARV( B2 ; A4:E200 ; 3 ; FALSO )
1. ¿Qué busco? (B2)

El RUN del estudiante escrito en la casilla de consulta.

2. ¿Dónde busco? (A4:E200)

Toda la nómina general de alumnos del liceo.

3. ¿Qué columna traigo? (3)

El número de columna con el dato deseado (ej: Teléfono Apoderado).

4. Coincidencia (FALSO)

Obliga a que el RUN sea 100% exacto.

Análisis Rápido: Tablas Dinámicas y Alertas Visuales

📊 Tablas Dinámicas Escolares

Convierte 300 filas de datos en un resumen de 4 líneas para el Director:

  1. Haz clic en tu planilla > Insertar > Tabla dinámica.
  2. Arrastra Especialidad TP a Filas.
  3. Arrastra Situación a Columnas.
  4. Arrastra RUN a Valores para totalizar aprobados y reprobados.

🎨 Semáforo de Formato Condicional

Las celdas cambian de color solas según el valor ingresado:

  • 🔴 Notas Rojas: Menor que 4.0 > Fondo rojo suave.
  • 🟢 Notas Sobresalientes: Mayor o igual a 6.0 > Fondo verde suave.
  • 🟡 Alerta Asistencia: Menor a 85% > Fondo amarillo.
